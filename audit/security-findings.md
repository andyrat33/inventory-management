# Security Findings — Inventory Management App

**Auditor:** security-auditor
**Scope:** `server/main.py`, `server/mock_data.py`, `server/generate_data.py`, `server/data/*.json`, `client/src/**`, dependency manifests.
**Date:** 2026-09-07

## Summary

The application is a demo with in-memory mock data and, by design, **no authentication or authorization on any endpoint** — every route in `server/main.py`, including the mutating `POST`/`DELETE`/`PATCH` endpoints and the financial `/api/spending/*` endpoints, is publicly reachable. The frontend "auth" is a hardcoded `isAuthenticated = ref(true)` with no router guards. The most serious concrete misconfiguration is CORS: `allow_origins=["*"]` combined with `allow_credentials=True` causes Starlette to reflect _any_ requesting origin back with `Access-Control-Allow-Credentials: true` — harmless only because no cookie/session auth exists yet, and it becomes critical the moment auth is added. Remaining issues are lower severity: unbounded/unvalidated request bodies with no rate limiting (memory-growth DoS against the in-memory lists), an unbounded `float` budget that can trigger an unhandled 500, CSV formula injection in the inventory export, binding to `0.0.0.0`, un-committed dependency lockfiles, and slightly stale dependency floors (`axios ^1.6.7`, `vite ^5.2.0`).

**Good news / not found:** No path traversal — `mock_data.load_json_file` only ever opens hardcoded, `BASE_DIR`-anchored filenames and no user input reaches a filesystem path. No SQL/command/`eval`/`exec`/`subprocess`/unsafe-deserialization patterns anywhere (no DB, no shell, no `pickle`/`yaml`; `json.load` on trusted local files only). No unsafe ID-based list indexing — lookups are linear `next(... item["id"] == id ...)` scans that return 404 on miss. No `v-html`/`innerHTML`/`eval` in the client, so no DOM XSS; Vue auto-escapes interpolations. FastAPI debug mode is off, so 500s return a generic message with no stack trace. No real secrets are committed (`.mcp.json` uses `${GITHUB_PERSONAL_ACCESS_TOKEN}` env interpolation, `.env` is gitignored, `.env.example` is empty). POST handlers build result dicts field-by-field (status forced server-side), so there is no mass-assignment exposure.

## Findings

| ------ | ----------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SEC-1  | No authentication/authorization on any endpoint                               | `server/main.py:246-516` (every route); mutating: `:440` POST `/api/tasks`, `:453` DELETE `/api/tasks/{id}`, `:462` PATCH `/api/tasks/{id}`, `:482` POST `/api/restocking-orders`; sensitive reads: `:332-350` `/api/spending/*`                    | **High** — every endpoint is world-readable and the mutation endpoints are world-writable with no credential of any kind; anyone who can reach the port can enumerate customers/vendors/financials and create/delete tasks and restocking orders. Severity held at High (not Critical) only because data is non-persistent mock data with no real PII.                                                                                                                                                                                                                                      | Add an auth dependency (API key or JWT bearer) as a global `APIRouter`/`Depends` gate; require it especially on all non-GET routes and `/api/spending/*`. Document the demo-only exception explicitly if left open.                                                              |
| SEC-2  | CORS: wildcard origin + credentials reflects any origin                       | `server/main.py:51-57`                                                                                                                                                                                                                              | **Medium** — verified against installed `starlette 1.3.1` (`middleware/cors.py:115-120`): with `allow_all_origins` and `allow_credentials` both true, the middleware echoes the request's `Origin` into `Access-Control-Allow-Origin` and sets `Access-Control-Allow-Credentials: true` for _every_ site. Blast radius is limited today (no cookies/session), but this is a latent Critical — any malicious page could make authenticated cross-origin calls the instant SEC-1 is fixed with cookie auth. Directly contradicts `server/CLAUDE.md` ("Never use wildcard (*) in production"). | Set `allow_origins=["http://localhost:3000"]` (explicit list from config/env) and keep `allow_credentials=True` only if actually needed; never pair `["*"]` with credentials.                                                                                                    |
| SEC-3  | Client-side-only auth, no route guards, stub logout                           | `client/src/composables/useAuth.js:92` (`isAuthenticated = ref(true)`), `:94-98` (logout = `alert()` only); `client/src/main.js:12-23` (no `router.beforeEach`)                                                                                     | **Medium** — there is no real auth to bypass, but the pattern (always-authenticated flag, no guarded routes, logout that does nothing) will give a false sense of protection and tends to ship as-is. Every view is reachable by URL.                                                                                                                                                                                                                                                                                                                                                       | When SEC-1 lands, drive `isAuthenticated` from real token state, add a `router.beforeEach` guard redirecting unauthenticated users to a login route, and make `logout()` clear the token and redirect.                                                                           |
| SEC-4  | Unbounded / unvalidated request bodies + no rate limiting → memory-growth DoS | `server/main.py:136-139` (`CreateTaskRequest`: `title`/`priority`/`dueDate` free-form `str`, no `max_length`, no enum, no date validation), `:440-451` (`tasks.append`), `:482-516` (`restocking_orders.append`); no rate-limit middleware anywhere | **Low/Medium** — unauthenticated callers can append unbounded entries and arbitrarily large strings to the process-global in-memory lists (`tasks`, `restocking_orders`), growing RSS until OOM; no throttling. Low individual impact, but trivially scriptable.                                                                                                                                                                                                                                                                                                                            | Add `Field(max_length=...)` constraints and a `Literal["high","medium","low"]` for `priority`; validate `dueDate` as a date; cap collection sizes or add per-IP rate limiting (e.g. `slowapi`).                                                                                  |
| SEC-5  | Unbounded `float` budget accepts `Infinity`/`NaN` → unhandled 500             | `server/main.py:173-175` (`CreateRestockingOrderRequest.budget: float`, no bound) and `:483`; contrast `:472` GET which correctly uses `Query(..., ge=0)`; consumed at `:211` `int(remaining_budget // c['unit_cost'])`                             | **Low** — Python's `json` module parses `Infinity`/`NaN` literals by default, so `{"budget": Infinity}` reaches `compute_restocking_recommendations`, where `int(inf // cost)` raises `OverflowError` → 500. Negative values are already handled (return 400). Pure availability nuisance.                                                                                                                                                                                                                                                                                                  | Constrain the model field: `budget: float = Field(ge=0, le=1_000_000_000)` and reject non-finite values (`pydantic` `allow_inf_nan=False`).                                                                                                                                      |
| SEC-6  | CSV formula injection in inventory export                                     | `client/src/views/Inventory.vue:236-242` (`escapeCsvField`), used at `:276`                                                                                                                                                                         | **Low** — `escapeCsvField` quotes fields containing `,` `"` or newline but does not neutralize a leading `=` `+` `-` `@` or tab, so a cell beginning with `=` executes as a formula when the file is opened in Excel/Sheets. Not exploitable today (values come from server-controlled inventory JSON), but the export is a spreadsheet sink and planned data (order notes, supplier names, user-entered task titles) is free-text.                                                                                                                                                         | Prefix any field whose first character is `= + - @ \t \r` with a single quote or a leading tab before quoting.                                                                                                                                                                   |
| SEC-7  | API server binds all interfaces                                               | `server/main.py:520` (`uvicorn.run(app, host="0.0.0.0", port=8001)`)                                                                                                                                                                                | **Low** — combined with SEC-1 (no auth) and SEC-4 (no rate limit), anyone on the LAN/VPN can reach the full API.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Bind `127.0.0.1` for local dev; make host configurable via env for deployment behind a reverse proxy.                                                                                                                                                                            |
| SEC-8  | Dependency lockfiles not committed                                            | `.gitignore:24` (`uv.lock`), `:25` (`*.lock`), `.gitignore` Node section (`client/package-lock.json`)                                                                                                                                               | **Medium** — neither the server (`uv.lock`) nor the client (`package-lock.json`) lockfile is version-controlled, and `server/pyproject.toml:6-10` pins lower bounds only (`fastapi>=0.110.0`, etc.). Builds are non-reproducible and a compromised future release of any transitive dep is pulled silently. The client lockfile omission is a documented tradeoff (CLAUDE.md — prevent private-registry leakage).                                                                                                                                                                           | Commit `uv.lock`. For the client, keep the public-registry `.npmrc` and commit `package-lock.json` alongside it (the `.npmrc` already pins the public registry, so the leak risk the gitignore guards against is mitigated) — or adopt `npm ci` against a lockfile stored in CI. |
| SEC-9  | Stale dependency floors (client)                                              | `client/package.json:13` (`axios ^1.6.7`), `:16` (`vite ^5.2.0`)                                                                                                                                                                                    | **Low** — `axios <1.8.2` is affected by CVE-2025-27152 (absolute-URL SSRF / credential leakage) and older follow-redirects issues; `vite 5.2.x` predates multiple 5.4.x path/`server.fs` advisories. The `^` range allows newer installs, but the committed floor and any stale `node_modules` stay vulnerable. Server deps actually resolve modern (`fastapi 0.141.1`, `starlette 1.3.1`, `pydantic 2.13.4`).                                                                                                                                                                              | Raise floors: `axios ^1.8.2`, `vite ^5.4.20` (or `vite 6.x` after testing); run `npm audit` in CI.                                                                                                                                                                               |
| SEC-10 | Fabricated PII committed to a public repo                                     | `client/src/composables/useAuth.js:5-11` (employee email `john.doe@catalystcomponents.com`, phone), `server/data/orders.json` / `transactions.json` (customer & vendor names)                                                                       | **Low** — all data is invented demo content, but the repo and forks are PUBLIC (per CLAUDE.md). Risk is future edits substituting real employee/customer/vendor data without noticing it becomes public.                                                                                                                                                                                                                                                                                                                                                                                    | Keep as-is but add a note to CLAUDE.md / PR checklist: no real names, emails, phone numbers, or customer/vendor identities in `data/` or `useAuth.js`.                                                                                                                           |

## Category checklist

| Category                                                                               | Result                                                                                                                                                                                             |
| -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Path traversal / unsafe file reads                                                     | **None.** `mock_data.load_json_file` (`server/mock_data.py:14-18`) joins hardcoded filenames under `BASE_DIR/data`; no request data reaches a path.                                                |
| SQL / command / template injection, `eval`/`exec`/`subprocess`, unsafe deserialization | **None.** No DB, no shell-out, no `eval`/`exec`, no `pickle`/`yaml`/`marshal`; only `json.load` on trusted local files.                                                                            |
| ID used to index data                                                                  | **Safe.** All `{id}` routes do linear `next((x for x in list if x["id"] == id), None)` and raise 404 on miss — no list-index or attribute lookup on attacker input.                                |
| Mass assignment on POST/PATCH                                                          | **None.** `create_task` and `create_restocking_order` construct the stored dict field-by-field; `status` is set server-side; `create_restocking_order` recomputes items server-side from `budget`. |
| Verbose errors / stack traces to client                                                | **None.** FastAPI debug not enabled; 500s return generic body. 404 `detail` echoes the path param as a JSON string (not HTML) — no injection sink.                                                 |
| DOM XSS                                                                                | **None.** No `v-html` / `innerHTML` / `eval` in `client/src`; Vue auto-escapes `{{ }}`.                                                                                                            |
| Committed secrets / internal hostnames                                                 | **None.** `.mcp.json` uses `${GITHUB_PERSONAL_ACCESS_TOKEN}`; `.env` gitignored; `.env.example` empty; only `localhost` URLs.                                                                      |
| Pydantic validation present                                                            | Mostly. Models exist for every response and request body; gaps are string/number _constraints_ (SEC-4, SEC-5), not missing models.                                                                 |
