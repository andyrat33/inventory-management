Factory Inventory Management — System Architecture

Vue 3 + FastAPI demo application backed by in-memory JSON mock data (no database).

1 System Architecture

A single-page Vue app talks to a FastAPI backend over HTTP/JSON. The backend loads a fixed set of JSON files into memory at startup and filters them in Python on every request — there is no persistence layer.

5 Notes

  • Filter system — four filters (time period, warehouse, category, order status) live in a singleton composable and are passed as query params to nearly every endpoint.
  • No database — all data is loaded from server/data/*.json into Python lists on import; writes made during a session (e.g. new tasks) are not persisted and reset on restart.
  • No auth layer — CORS allows all origins and there is no authentication; suitable for local demo use only.
  • Reactivity pattern — raw API responses are held in ref()s, with derived values (totals, chart data) computed from them via computed().
